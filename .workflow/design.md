# Sprint Design

Generated by workflow designer.

## S1: Extend contextHash suppression to all ContextModes

**Goal:** Hash the full combined content (staticCtx + dynamicCtx) and apply suppression for ALL ContextMode values, not just ContextModeResume. Zero both staticCtx and dynamicCtx when the combined hash matches the stored value. This fixes the primary cache-miss regression: in sticky-Claude mode every turn returns to ROUTING, so the next turn enters ContextModeReturning and the current guard never fires.

**Files:** cmd/milk/runner.go

**Tests:** Run go test ./cmd/milk/... to confirm no regressions. Manual: start milk TUI, send 3+ turns in sticky-escalation mode; confirm obs.Debug logs show cache_read increasing and cache_write falling to near-zero after the first turn. Verify /escalate fresh still injects a full context block (nonce change makes the combined hash differ).

**Depends on:** none

## S2: Zero lastEscalationContextHash on ForceFreshEscalation

**Goal:** When /escalate fresh clears EscalationNonce and EscalationSessionID, also zero lastEscalationContextHash in TUI model state so a stale hash from the previous context cannot suppress injection of the fresh session's first context block. Capture forceFresh before the turn runs and zero the field in the agentDoneMsg handler.

**Files:** cmd/milk/repl.go

**Tests:** Run go test ./cmd/milk/... for no regressions. Manual: /escalate fresh followed by several turns — confirm context is injected on the fresh turn and cached on subsequent ones.

**Depends on:** S1

## S3: Add ContextModeContinuation for uninterrupted sticky turns

**Goal:** Add a fourth ContextMode for 'Claude is already active and the user typed the next message directly': EscalationSessionID != '' AND LocalTurnsSinceLastEscalation() == 0. BuildStaticContext returns '' for it (like ContextModeResume); BuildDynamicContext returns only the summary-diff block. This suppresses redundant identityBlock and escalationBrief re-injection that currently occurs on every ContextModeReturning turn in sticky mode, further reducing injected bytes and cache churn.

**Files:** internal/escalation/builder.go, internal/escalation/builder_test.go, cmd/milk/dispatch.go

**Tests:** Add table-driven test cases in internal/escalation/builder_test.go for ContextModeContinuation verifying BuildStaticContext returns '' and BuildDynamicContext returns only the summary diff. Run go test ./internal/escalation/... and go test ./cmd/milk/.... Manual: consecutive sticky turns — confirm cache_read tokens climb and no identityBlock is re-injected.

**Depends on:** S1
