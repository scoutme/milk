# milk website

Marketing homepage + docs site, built with MkDocs Material.

Docs content is not duplicated here: `docs_dir` in `mkdocs.yml` points
straight at the repo's `../docs`. Edit the source docs and the site picks
it up on the next build — no separate copy to keep in sync.

```sh
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
mkdocs serve      # live-reload dev server at http://127.0.0.1:8000
mkdocs build      # outputs to site/
```

Only `setup.md`, `providers.md`, `spec.md`, `eval.md`, and `adr/` are
published (see `exclude_docs` in `mkdocs.yml`) — internal design/planning
notes stay out of the public site.

The homepage (`/`) is not autogenerated from a doc: `docs/index.md` just
sets `template: home.html`; `overrides/home.html` holds the actual
hero/marketing markup, kept separate from the technical docs on purpose.
